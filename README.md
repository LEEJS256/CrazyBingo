# 🎮 크레이지 빙고 (Crazy Bingo) - 커스텀 레크레이션 빙고 게임
> 대규모 참가자(20~30명) 대상 실시간 레크리에이션 퀴즈 게임입니다.

---

## 📌 1. 프로젝트 소개

Crazy Bingo는 여행, MT, 친목 모임 등에서 진행할 수 있는 팀 대항 빙고 퀴즈 게임입니다.

기존 PPT 기반 퀴즈 진행 방식의 불편함을 해결하기 위해 제작되었으며, 진행자는 전용 호스트 화면을 통해 문제를 관리하고 정답 판정 및 점수 계산을 수행할 수 있습니다.

참가자는 빙고판을 통해 게임을 진행하며, 문제를 맞힐 때마다 빙고를 완성하여 승리를 목표로 합니다.

- **개발 기간**: 2026.05 ~ 2026.06 
- **개발 인원**: 1명 

---

## 🛠 2. 기술 스택 (Tech Stack)
- **Engine**: Unreal Engine 5 (UE 5.6)
- **Language**: C++, Blueprint
- **Framework**: UMG (Unreal Motion Graphics), `UListView` Architecture
- **IDE**: JetBrains Rider

---

## 🚀 3. 주요 기능 (Key Features)

### 🔹 1) 런타임 퀴즈 가공 및 세이브 데이터 기반 관리 시스템
- **4종 멀티 퀴즈 타입 지원**: 단답형, 객관식, 초성 퀴즈, 유튜브 음악 퀴즈 등 각기 다른 데이터 구조를 가진 문제 유형을 완벽히 지원하며, 동적 UI 분기를 통해 실시간으로 폼을 편집할 수 있습니다.
- **유연한 세이브 데이터 아키텍처**: 호스트가 커스텀하게 작성한 문제셋을 세이브 데이터로 영구 보존할 수 있습니다. 게임 시작 시 **[어떤 세이브 데이터를 불러올 것인지]**와 **[이 중 몇 개의 문제를 게임에 사용할 것인지]**를 진행자가 자유롭게 스케일링하여 선택할 수 있는 유연성을 제공합니다.
- **DataTable 기반 직렬화**: 런타임 중 호스트가 자유롭게 생성, 편집한 가상 데이터는 최종적으로 데이터 테이블 구조와 안전하게 매칭되어 무결성 있게 직렬화 및 관리됩니다.

### 🔹 2) 가상화 리스트뷰(UListView) 기반 문제 테이블 관리
- **메모리 최적화 렌더링**: 대량의 문제를 버벅임 없이 안정적으로 관리하기 위해 `IUserObjectListEntry` 인터페이스와 가상 데이터 오브젝트를 적용했습니다. 화면에 보이는 만큼만 위젯을 풀링(Pooling)하여 렌더링 비용을 대폭 최적화했습니다.
- **독립 컬럼 아키텍처 (UX 개선)**: 기존의 유지보수가 불가능했던 단순 문자열 포맷팅 결합 방식을 탈피했습니다. **[문제 내용 / 카테고리 / 점수 / 문제 유형]**을 각각 독립적인 컬럼 블록으로 완전히 분리 레이아웃화하여 호스트가 수많은 문제 정보를 한눈에 판별할 수 있도록 가독성을 극대화했습니다.
- **실시간 데이터 바인딩**: 리스트뷰에 장전된 아이템 슬롯을 호스트가 선택하는 즉시 세부 편집 디테일 폼과 연동되어 실시간 데이터 수정 및 개별 소거가 가능합니다.

### 🔹 3) 체크박스를 활용한 무결성 다중 일괄 삭제(Multi-Delete) 시스템
- **명시적 다중 컨트롤 UX**: 목록 내의 행마다 독립적인 체크박스를 배치하여, 호스트가 제어(일괄 삭제 등)하고자 하는 문제들을 직관적이고 가시적으로 인지하고 다중 조작할 수 있도록 안전장치를 마련했습니다.
- **양방향 상태 동기화**: 리스트뷰 위젯이 스크롤되어 화면 밖으로 밀려나 파괴(가상화)되더라도 체크 상태가 무의미하게 증발하지 않도록, Row 위젯의 체크박스 상태를 가상 데이터 오브젝트(`UCB_QuestionListData`)와 실시간으로 연동하여 보존합니다.

### 🔹 4) 호스트 전용 실시간 게임 세션 컨트롤러
- **진행자 핵심 대시보드**: 게임 진행 중 현재 출제된 문제의 **[정답]**과 **[힌트]**를 호스트 화면에만 직관적으로 실시간 모니터링 피드백을 제공하며, 이를 바탕으로 정확하고 공정한 승자 판정을 내릴 수 있도록 지원합니다.
- **글로벌 게임 매니지먼트**: 라운드별 승리 팀 판정, 팀별 점수 실시간 합산 및 가감 기능, 그리고 전체 빙고 진행 스냅샷 상태를 완벽하게 제어하여 서버/세션에 실시간으로 브로드캐스팅합니다.

💡 기술적 도전 과제

UI 머티리얼을 활용한 배경 제작

프로젝트에 적합한 배경 에셋을 구하기 어려웠기 때문에 단순 이미지 사용 대신 UI 요소와 머티리얼을 활용하여 직접 배경을 구성했습니다.

Border, Overlay 등 UMG 위젯을 조합하여 기본 레이아웃 구성
UI 전용 머티리얼을 제작하여 움직이는 격자(Grid) 패턴 구현
Panner 노드를 활용해 배경이 지속적으로 움직이는 효과 적용
별도의 배경 이미지 없이도 게임의 분위기와 시인성을 확보

이를 통해 적은 리소스로도 프로젝트의 콘셉트에 맞는 동적인 UI 배경을 구현할 수 있었습니다.

YouTube 링크 재생 방식 개선

초기에는 게임 내부에서 직접 YouTube 영상을 재생하는 방식을 구현했습니다.

이를 위해 다음과 같은 과정을 적용했습니다.

URL 파싱
Embed URL 변환
HTML iframe 동적 생성
WebBrowser 위젯을 통한 영상 재생

하지만 YouTube 정책 변경, 브라우저 호환성 문제, Unreal Engine 환경에서의 불안정성 등으로 인해 유지보수 비용이 증가할 가능성이 있었습니다.

이에 따라 최종적으로는 게임 내에서 영상을 직접 재생하는 대신, 저장된 YouTube 링크를 웹 페이지 형태로 표시하는 방식으로 구조를 변경했습니다.

이를 통해 다음과 같은 장점을 얻을 수 있었습니다.

YouTube 정책 변경에 대한 의존성 감소
브라우저 호환성 문제 최소화
유지보수 비용 절감
보다 안정적인 음악 퀴즈 진행 환경 제공
