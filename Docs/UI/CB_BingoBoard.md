# 🖥️ CB_BingoBoard - 메인 인게임 플레이 및 통합 전광판 시스템

> Crazy Bingo 프로젝트의 실시간 플레이 화면을 총괄하며, 빙고판 생성, 문제 배정, 실시간 빙고 라인 연산, 중앙 문제 출력, 그리고 팀별 스코어 전광판 처리까지 인게임 플레이의 모든 기믹을 총괄하는 메인 핵심 UMG 위젯 시스템입니다.

---

## 📌 1. 개요

- **클래스**: `UCB_BingoBoard` (`UUserWidget` 상속)
- **통합 서브 위젯**:
    - `UCB_QuestionBoard` (중앙 문제 및 유형별 보기/힌트 출력 보드)
    - `UCB_BingoScoreBoard` (상단 실시간 팀별 점수 및 빙고 줄 수 전광판)
- **역할**: 크기별 빙고판 가변 생성, 무작위 문제 매핑, 유형별 문제 출제 분기, 실시간 스코어 및 빙고 연산, 최종 예외 조건 종료 처리

---

## 🚀 2. 주요 핵심 서브 위젯 기능

### 🔹 1. UCB_QuestionBoard (중앙 문제 출력 시스템)
빙고 셀이 선택되었을 때 해당 칸에 매핑된 `FCB_DataTable_Question` 구조체 데이터를 전달받아, 문제 유형별 전용 인풋 폼으로 화면을 자동 스위칭하고 멀티미디어 에셋을 출력합니다.

**구현 내용**
- **공통 텍스트 및 배점 출력**: 문제 내용(`Text_QuestionBody`)을 기입하고, 문제 고유의 배점 데이터를 파싱하여 `[X점]` 형태의 문자열로 전면에 렌더링합니다.
- **외부 이미지 디스크 동적 로드**: 이미지 경로(`ImageAssetPath`)가 유효할 경우 `FImageUtils::ImportFileAsTexture2D` 라이브러리를 통해 디스크 상의 외부 이미지를 런타임에 `UTexture2D`로 즉각 변환하여 프리뷰 화면(`Image_QuestionPhoto`)을 구성합니다. 이미지가 없는 순수 텍스트 문제일 경우 위젯의 가시성을 `Collapsed`로 강제 전환하여 레이아웃을 안전하게 접어버립니다.
- **유형별 위젯 스위처 분기 (`UWidgetSwitcher`)**:
    - `MultipleChoice (객관식)`: 상단 타이틀을 '객관식 퀴즈'로 교체하고 스위처를 0번 방으로 전환한 뒤, 4개의 보기 배열을 안전성 체크를 거쳐 `Text_Choice_1~4` 컴포넌트에 매칭합니다.
    - `InitialSound (초성)`: 타이틀을 '초성 퀴즈'로 교체하고 1번 방을 활성화한 후, 자음 데이터 플래그를 `힌트 초성: X` 형태로 출력합니다.
    - `YoutubeLink (음악/영상)`: 타이틀을 '음악/영상 퀴즈'로 교체하고 2번 방을 오픈하여 동영상 연동 레이아웃을 구성합니다.
    - `ShortAnswer (단답형)`: 타이틀을 '단답형 주관식'으로 교체하고 3번 방 전용 UI를 화면에 노출합니다.

### 🔹 2. UCB_BingoScoreBoard (상단 전광판 시스템)
실시간으로 변동되는 양 팀의 누적 점수, 현재 달성한 빙고 줄 수, 그리고 게임 인스턴스에 설정된 팀 고유 컬러를 전광판 스크린에 실시간 표기합니다.

**구현 내용**
- **천 단위 콤마 문자열 변환**: 팀의 점수를 출력할 때 순수 정수형 데이터를 그대로 밀어 넣지 않고, 언리얼 내장 함수인 `FText::AsNumber()`를 호출하여 숫자에 천 단위 콤마(,)가 자동으로 찍히도록 정교하게 예외 렌더링 처리를 수행합니다 (`RefreshScoreUI`).
- **글로벌 팀 컬러 실시간 동기화 (`RefreshTeamColor`)**: `UCB_GameInstance`를 캐스팅하여 에디터 또는 옵션 창에서 변경된 각 팀의 상징 색상인 `GetTeamColor(true/false)` 값을 추출한 뒤, 전광판 팀 이름 텍스트(`Text_TeamName_1 / 2`)의 `SetColorAndOpacity` 속성에 다이렉트로 바인딩합니다.
- **계층 구조 역추적 기반 메인 메뉴 복귀**: 복귀 버튼 클릭 시 `GetTypedOuter<UCB_BingoBoard>()` 컴포넌트 헬퍼 함수를 기동하여 상위 위젯 레이어 계층 구조를 안전하게 역추적합니다. 부모 보드판 주소가 유효하게 잡히는 순간 최종 복귀 함수(`ReturnToMainMenu`)를 트리거하여 널 크래시 없이 안전하게 메인 화면으로 유저 페이지를 탈출시킵니다.

## 🚀 3. 메인 보드판 제어 기능 (CB_BingoBoard Core)

### 🔹 1. 크기 가변형 빙고판 생성 및 무작위 번호 배치
게임 설정창에서 결정된 인덱스 규격(`3x3` ~ `7x7`)을 전달받아, 그리드 패널 레이아웃을 동적으로 빌드하고 무작위 번호와 문제 카테고리를 자동 배치합니다.

**구현 내용**
- `InitBoard()` 가 기동되면 그리드의 모든 자식들을 청소하고 무작위 문제를 새로 수집합니다.
- 총 칸 수에 맞는 정수 배열(Numbers)을 생성한 뒤 난수 기반 셔플(`Swap`) 처리를 진행하여 중복 없는 랜덤 빙고 번호 리스트를 직접 구성합니다.
- `BingoCellClass` 위젯을 동적 생성하여 **[번호 / 실제 카테고리 / 부모 보드판 주소(this) / 고유 셀 인덱스]**를 완벽하게 주입한 뒤, 전광판 UI 초기화(`RefreshScoreUI`, `RefreshTeamColor`)를 동시 원격 호출합니다.

### 🔹 2. 전수 조사 기반 빙고 라인 연산 및 무한 루프 버그 방지
어느 한 팀이 셀을 점령할 때마다 보드 전체 행렬 공간을 완전히 스캔하여 가로, 세로, 양방향 대각선 줄이 연결되었는지 전수 판정을 수행합니다.

**구현 내용**
- **라인 체크**: 이중 루프를 설계하여 모든 행과 열을 순회합니다. 특정 라인 검사 시 한 칸이라도 체크박스가 꺼져 있거나(`!Cell->bSelected`), 점령한 팀 번호가 다를 경우 플래그를 차단(`bLine = false`)하여 오작동을 차단합니다. 단일 루프를 통해 주대각선(`\`)과 부대각선(`/`)의 점령 상태를 개별 검사합니다.
- **[버그 수정] 풀이 완료 칸 추적**: 중간에 오답이 섞여 양 팀 모두 목표 빙고 줄 수에 영원히 도달하지 못해 게임이 무한 루프에 빠지는 치명적인 기획적 결함을 방지하기 위해, 정오답 여부를 떠나 `Cell->bSelected`가 참(`true`)인 **'풀이가 완료된 모든 칸'의 개수(`TotalSelectedCells`)를 전수 추적**하는 카운트 방어선을 구축했습니다.

### 🔹 3. 승리 조건 이원화 판정 및 양방향 참조 결과창 호출
게임의 정상 종료 조건(목표 라인 도달)과 예외 종료 조건(보드판 꽉 채워짐)을 모두 만족할 수 있는 이원화 판정 시스템을 통해 최종 승리팀을 가려냅니다.

**구현 내용**
- **정상 종료**: `GI->GetTargetBingo()`로 기획된 목표 값을 가져와 대조한 뒤, 어느 팀이든 선행 도달 시 즉각 최종 승리 판정을 내립니다.
- **예외 종료 (올킬 판정)**: 빙고 줄 수는 미달이지만 판이 가득 찬 경우, `GI->TeamAScore`와 `TeamBScore`를 직접 비교 연산하여 **누적 점수가 단 1점이라도 더 높은 팀에게 최종 승리**를 부여합니다. 점수까지 동점일 경우 A팀 판정승 등으로 안전하게 우회 처리합니다.
- 판정이 완료되면 결과 위젯 클래스(`UCB_ResultPopup`)를 동적 생성하고, **양방향 참조 통로(`ResultWidget->OwnerBoard = this`)를 다이렉트로 개통**한 뒤 데이터를 세팅하고 화면에 배치합니다.
