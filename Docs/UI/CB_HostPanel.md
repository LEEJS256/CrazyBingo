# 🖥️ CB_HostPanel - 진행자 조작 패널 및 유튜브 미디어 제어 시스템

> 게임 진행자(호스트)가 독립된 외부 Slate Window 창을 통해 인게임 플레이 보드를 실시간 원격 제어하고, 정답/오답 판정 및 유튜브 음악 퀴즈 링크를 다이내믹하게 실행할 수 있는 대화상자 조작 콘솔 위젯입니다.

---

## 📌 1. 개요

- **클래스**: `UCB_HostPanel` (`UUserWidget` 상속)
- **역할**: 현재 출제된 문제의 힌트/정답 시각화, 수동 정답 팀 판정 및 무효 처리 원격 통보, 타임스탬프 지원 유튜브 URL 파싱 및 외부 프로세스 제어, 실시간 칸 문제 리롤 트리거
- **연동 대상**: `UCB_BingoBoard`(메인 게임 플레이 보드판)

---

## 🚀 2. 주요 기능

### 🔹 1. 문자열 조립 기반 유튜브 영상 ID 및 타임스탬프 정밀 파싱 (YouTube Media Control)
음악 및 영상 퀴즈 유형이 발동되어 문제 데이터가 인입될 때, 입력된 유튜브 주소를 분석하여 순수 비디오 식별값과 시작 재생 시간 옵션을 가공 추출한 뒤 OS 네이티브 브라우저로 동적 실행합니다.

**구현 내용**
- **타임스탬프 파싱**: URL 내에 특정 시작 시간 플래그인 `t=` 옵션이 발견되면, `RightChop()` 함수와 앰퍼샌드(`&`) 위치 검색 연산을 거쳐 타임 파라미터(`TimeParam`) 정보만 분리해 냅니다.
- **비디오 ID 정밀 추출**: 일반 PC용 주소(`watch?v=`) 형태와 공유용 축약 주소(`youtu.be/`) 형태 모두 대응 가능하도록 고유 오프셋 지표(`ParamIndex + 8` 또는 `SlashIndex + 9`)를 역산하여 유튜브 고유 11자리 식별자(`VideoID`)를 캡처합니다.
- **외부 브라우저 실행**: 가공 완료된 문자열을 토대로 재생 최적화 임베드 링크(`https://www.youtube.com/v/...`)로 재조립을 단행합니다. 
이때 **`VideoID`가 비어있지 않을 때만** 운영체제 핵심 API인 `FPlatformProcess::LaunchURL()`을 기동함으로써 널 주소 참조 크래시를 완벽히 차단합니다.

### 🔹 2. 진행자 화면 전용 힌트 및 정답 출력 분기 (Host Preview)
플레이어들이 바라보는 메인 전광판 화면에는 퀴즈의 문제 본문과 카테고리만 노출되지만, 진행자용 호스트 창에는 매끄러운 게임 조율을 위해 데이터 필드를 치환하여 요약 브리핑합니다.

**구현 내용**
- `SetCurrentQuestionInfo()`가 작동하는 순간 현재 열린 칸 정보(`CellIndex`)를 내부 캐싱 변수인 `CachedCellIndex`에 저장합니다.
- 그 후 호스트 패널 텍스트 컴포넌트 구조에 매핑을 수행할 때, 실제 문제 내용 대신 퀴즈 힌트 내용(`QuestionData.Hint`)을 상단 칸(`Text_CurrentQuestion`)에 뿌려주고 해설 및 정답 데이터(`QuestionData.Answer`)를 요약 칸(`Text_Explanation`)에 동기화하여 진행자 전용 인터페이스를 완성합니다.

### 🔹 3. 독립 무선 통신 기반 원격 팀 점령 및 무효 제어 (Remote Cell Occupation)
진행자가 플레이어들의 오프라인 정답 외침을 듣고 패널의 제어 버튼을 클릭하는 순간, 메인 보드판 위젯의 상태를 실시간 하이재킹하여 강제 점령 및 상태 변경 명령을 통보합니다.

**구현 내용**
- **A팀 정답 처리 (`OnTeamAWinClicked`)**: 연결된 `TargetBingoBoard` 참조 유효성을 체크한 뒤 `SetCellOwnerByHost(1)`을 원격 호출하여 A팀 상징 색상 변경 및 글로벌 누적 스코어 배점 합산 연산을 수행합니다.
- **B팀 정답 처리 (`OnTeamBWinClicked`)**: 동일 공정 메커니즘을 타며 보드판의 `SetCellOwnerByHost` 함수에 `2`번 식별 코드를 던져 B팀 점령을 확정 짓습니다.
- **오답 및 무효 처리 (`OnWrongAnswerClicked`)**: 양 팀이 정답에 도달하기 힘들다고 판단되거나 오답 처리가 필요할 경우, `SetCellOwnerByHost(3)`을 던져 해당 칸을 무효화 및 강제 완료 처리 라인으로 넘깁니다.

### 🔹 4. 실시간 캐시 인덱스 연동형 칸 문제 리롤 트리거 (Remote Reroll)
진행자가 현재 출제된 문제가 해당 레크리에이션 분위기에 적합하지 않다고 판단하여 '리롤(새로고침)' 버튼을 누르면, 캐싱된 인덱스를 토대로 메인 보드판의 퀴즈 풀 교체 함수를 작동시킵니다.

**구현 내용**
- `RerollCellQuestion()` 콜백 이벤트가 발동되면, 현재 선택되어 열린 칸이 존재하는지 `CachedCellIndex` 유효성 검사 방어선(`CachedCellIndex >= 0`)을 작동시킵니다.
- 통과 시 `TargetBingoBoard->RerollCellQuestion(CachedCellIndex)`을 다이렉트로 원격 호출하여, 보드판 내부에서 중복 검증 필터링 처리가 끝난 청정 퀴즈 데이터 풀 1종을 할당받아 해당 칸의 카테고리 및 해설 정보를 실시간 전면 리프레시하도록 명령을 전달합니다.
