# 🖥️ CB_AddQuestion - 퀴즈 문제 생성 및 편집 메인 시스템

> Crazy Bingo 프로젝트에서 퀴즈 문제를 생성, 수정, 삭제하고 로컬 세이브 파일과 연동할 수 있는 퀴즈 관리 메인 UMG 위젯입니다.
> 입력된 문제의 유형별 분기 처리, 리스트뷰 필터링, 그리고 외부 이미지 로딩 등 관리자 전용 편집 인터페이스의 핵심 제어 로직을 담당합니다.

---

## 📌 1. 개요

- **클래스**: `UCB_AddQuestion` (`UUserWidget` 상속)
- **역할**: 퀴즈 데이터 수집/추가/수정/역순 삭제, 유형별 필터링 조회, 이미지 에셋 경로 등록
- **연동 대상**: `UCB_QuestionListData`(리스트뷰 아이템 오브젝트), `UCB_SaveDialog`(세이브 팝업 창), `UCB_GameInstance`(최종 디스크 저장소)

---

## 🚀 2. 주요 기능

### 🔹 1. 문제 데이터 신규 추가 및 선택 수정 (Add & Modify)
사용자가 입력 필드에 작성한 텍스트 및 설정값들을 기반으로 구조체를 조립하여 런타임 마스터 배열에 반영합니다.

**구현 내용**
- **신규 추가 (`OnAddClicked`)**: 카테고리, 문제 내용, 정답, 점수, 보기(최대 4개) 등의 데이터를 취합하여 `FCB_DataTable_Question` 구조체를 동적 생성한 뒤 `TemporaryQuestionList` 마스터 배열에 무조건 추가(Add)합니다.
- **선택 수정 (`OnModifyButtonClicked`)**: 리스트뷰 아이템 중 체크박스가 단 하나만 선택되었는지 검증(`CheckedCount == 1`)하는 방어선을 구축한 후, 수정된 최신 입력창 데이터로 해당 배열 인덱스의 구조체를 그대로 덮어씁니다. 작업 완료 후 인풋 필드 청소 및 체크박스 비활성화를 처리합니다.

### 🔹 2. 안전한 인덱스 역순 삭제 (Safe Reverse Delete)
리스트뷰에서 다중 선택된 문제 데이터들을 마스터 배열에서 완전히 영구 제거합니다.

**구현 내용**
- 일반적인 정방향 루프 삭제 시 배열의 인덱스가 앞으로 밀리면서 엉뚱한 데이터가 지워지거나 `Index Out of Bounds` 크래시가 발생할 수 있습니다.
- 이를 방지하기 위해 `AllItems.Num() - 1`부터 `0`까지 **역순(뒤에서부터)으로 루프를 순회**하며 체크박스가 켜진 대상을 검색하고 `TemporaryQuestionList.RemoveAt(i)`을 수행하여 안전성을 확보했습니다.
- 체크박스를 통한 복수의 문제 삭제 가능 

### 🔹 3. Windows 데스크톱 탐색기 연동 및 외부 이미지 런타임 로드
문제를 출제할 때 참고할 실제 PC 내부의 외부 이미지 파일을 유저가 직접 탐색하고 UI에 실시간 미리보기로 띄울 수 있도록 지원합니다.

**구현 내용**
- `IDesktopPlatform` 모듈의 `OpenFileDialog` 인터페이스를 호출하여 윈도우 OS 네이티브 파일 탐색기 팝업을 구동합니다.
- 이미지 확장자(`*.png;*.jpg;*.jpeg`) 필터를 거쳐 선택된 파일의 절대 경로를 `SelectedAbsoluteImagePath`에 caches합니다.
- 언리얼 엔진의 `FImageUtils::ImportFileAsTexture2D` 라이브러리를 사용해 디스크 상의 이미지를 런타임 도중에 `UTexture2D` 에셋으로 동적 변환한 뒤, `Image_Preview` 위젯의 브러시로 등록해 미리보기 화면을 구성합니다.

### 🔹 4. 문제 유형별 입력 폼 자동 스위칭 및 필터링 (Widget Switcher & Filter)
콤보박스의 선택 상태에 따라 화면에 필요한 입력 UI 영역을 자동으로 교체하고 리스트뷰 목록을 조건별로 필터링합니다.

**구현 내용**
- **UI 스위칭 (`OnQuestionTypeChanged`)**: `UWidgetSwitcher`를 연동하여 객관식(0번), 초성(1번), 유튜브 링크(2번), 단답형(3번) 인덱스를 활성화해 기획에 맞는 전용 서브 인풋 폼만 화면에 정교하게 노출시킵니다.
- **유형별 필터링 (`RefreshListView`)**: 필터 콤보박스가 '전체보기'가 아닐 경우, 각 구조체의 Enum 타입(`ECB_QuestionType`)을 한글 문자열과 매칭 검사하여 일치하는 문제 데이터만 리스트뷰 목록 주머니(`UCB_QuestionListData`)로 할당해 화면을 새로고침합니다.

### 🔹 5. 양방향 데이터 주소 이관 기반 세이브 팝업 호출 (Save Dialogue Integration)
메인 화면의 임시 리스트 데이터를 물리 파일 시스템에 기록하기 위해 독립 세이브 다이어로그 위젯을 화면에 띄우고 상호 참조 주소를 연결합니다.

**구현 내용**
- `OnSaveButtonClicked()` 함수 실행 시 사전에 등록된 `SaveDialogClass` 위젯을 플레이어 컨트롤러 기반으로 동적 생성합니다.
- 위젯 생성 직후 `SaveDialog->SetOwningWidget(this)`를 호출하여 세이브 팝업창 내부 멤버 변수에 **메인 화면인 자기 자신의 인스턴스 주소(`this`)를 명시적으로 전달 및 각인**시킵니다.
- 이를 통해 세이브 팝업창이 닫히거나 확정될 때 메인 화면의 `TemporaryQuestionList` 데이터를 온전하게 넘겨받아 안전하게 디스크 IO 저장을 처리할 수 있도록 통로를 개설합니다.
